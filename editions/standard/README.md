# BergOS Standard Edition

**BergOS Standard** is the flagship edition of the project, designed for modern computers and workstation hardware.

Combining the solid foundation of Ubuntu LTS / KDE Neon with the cutting-edge **KDE Plasma** desktop environment, BergOS Standard delivers a powerful, fluid, and highly customizable user experience out of the box.

---

## Key Features

- **Modern Desktop:** Powered by KDE Plasma, offering sleek visuals, low resource usage relative to performance, and extensive customization options.
- **Calamares Installer:** Simple, fast, and reliable graphical installation process.
- **Universal Package Support:** Native APT package management combined with Flatpak and Flathub integration for access to the latest applications.
- **Gaming & Multimedia Ready:** Optimized kernel defaults and driver stack support for NVIDIA, AMD, and Intel graphics.
- **Modern Display Server:** Support for Wayland with X11 fallback options where appropriate.

---

## Technical Specifications

- **Architecture:** 64-bit (`x86_64`)
- **Base System:** KDE Neon / Ubuntu LTS
- **Desktop Environment:** KDE Plasma
- **Installer:** Calamares
- **Display Manager:** SDDM
- **Audio Stack:** PipeWire
- **Network Management:** NetworkManager
- **Package Management:** APT, Flatpak (Flathub enabled)

---

## Minimum System Requirements

- **Processor:** 64-bit Dual-Core CPU (2.0 GHz or higher)
- **RAM:** 4 GB minimum (8 GB recommended)
- **Storage:** 25 GB available disk space
- **Graphics:** OpenGL 3.0 capable graphics card
