# BergOS Retro Edition

**BergOS Retro** is a specialized edition designed to revive legacy computers and vintage hardware that lack 64-bit processor support.

While modern operating systems have phased out older hardware architectures, BergOS Retro builds upon **Debian 12 (Bookworm) 32-bit (`i386`)** to provide a functional, stable, and secure operating system for 32-bit computers.

---

## Key Features

- **32-Bit Architecture Support:** Native support for `i386` processors (Intel Pentium, Atom, early Core Duo, AMD Athlon XP, etc.).
- **Debian 12 Foundation:** Unmatched rock-solid stability and long-term package support from Debian.
- **Extremely Low Memory Footprint:** Efficient XFCE desktop configuration designed to run comfortably on sub-2GB RAM systems.
- **Legacy Compatibility:** Full X11 support, tailored driver defaults, and lightweight application choices.
- **Modern Calamares Setup:** A graphical installer making 32-bit Linux setup modern and straightforward.

---

## Technical Specifications

- **Architecture:** 32-bit (`i386` / `i686`)
- **Base System:** Debian 12 (Bookworm)
- **Desktop Environment:** XFCE
- **Installer:** Calamares
- **Display Manager:** LightDM
- **Display Server:** X11
- **Package Management:** APT (Debian Repositories)

---

## Minimum System Requirements

- **Processor:** 32-bit x86 Processor (1.0 GHz or better)
- **RAM:** 512 MB minimum (1 GB or more recommended)
- **Storage:** 10 GB available disk space
- **Graphics:** Basic legacy GPU / integrated graphics
